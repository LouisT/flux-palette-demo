This is a **demonstration project**. It exists solely to show how the Flux Palette theme handles project layouts, image galleries, and feature lists.

## Purpose of this Demo

* **Visual Test**: To verify that the dark/light mode switching works correctly with project content.
* **Layout Check**: To ensure the sticky sidebar interacts correctly with longer project descriptions.
* **Asset Loading**: To test the lazy-loading of gallery images.
